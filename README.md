# Verbos de Moçambique

Flashcards for 44 Portuguese verbs, with spaced repetition, pronunciation (iPhone/Mac text-to-speech, Portugal voice), plain-English tense explanations, and example sentences set in Mozambique.

Live: https://djeppsonbestdayhr.github.io/verbos/

Everything is in `index.html`. Progress is saved in each person's browser.
